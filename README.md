A single-line museum label from the year 3000, written for the Museum of the Year 3000 bounty: a deadpan plaque beside an ordinary object from today, in which future curators confidently misread what the thing was for. The program validates the line (UTF-8, 1–200 characters, not only whitespace) and writes it deterministically to the entry file.

## Run it

```sh
python3 main.py
```
